
# WALS Linguistic Association Analysis

## Project Overview

This project investigates associations between grammatical word-order patterns and tonal features across the world's languages using data from the World Atlas of Language Structures (WALS).

Apriori association-rule mining will be used to identify frequent patterns and relationships between linguistic features.

## Research Question

What associations exist between dominant grammatical word-order patterns and tonal features across the world's languages, and how do these associations vary across language families and geographical regions?

## Research Objectives

1. Identify the most frequent combinations of word-order patterns and tonal features.
2. Investigate associations that are stronger than expected by chance using support, confidence and lift.
3. Compare linguistic patterns across language families and geographical regions.

## Dataset

- Name: World Atlas of Language Structures (WALS)
- Version: v2020.6
- Website: https://wals.info/
- Download: https://wals.info/download
